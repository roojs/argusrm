# Changelog

All notable changes to Argus Remote Management are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and release tags use [Semantic Versioning](https://semver.org/).

`CHANGELOG.md` is the source of truth for release notes and Debian/RPM
package changelogs.

## [0.1.0] - Unreleased

### Added

- Initial Argus server, agent, and command-line controller.
- Debian and Fedora RPM packages for all three programs.
- Systemd services for the server and Linux agent.
- Changelog-verified, tag-driven GitHub releases.
- Controller AppImage, Windows installer, and Android APK workflows.
