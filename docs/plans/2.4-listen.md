## Purpose

- ✔️ `Listen.start` must read `agent.run` on the open app socket.
- ⏳ `argus-controller --agent ID --command LINE` then prints stdout and exits.
- ✔️ Server already writes `agent.run`. `Listen.start` now watches.
- ℹ️ [5.0-controller.md](5.0-controller.md). [RPC commands](../rpc-commands.md).
- ℹ️ Reproduce: `sudo argus-controller --agent 1 --command "ls -l /home/alan"`.
  - Server: `run … on agent 1`.
  - Agent log has no command.
  - Controller waits until Ctrl+C.

---

## Why this is a sub-plan

- 🔷 The handler is already `Listen.notification`.
- 🔷 `start` is a stub. It logs and returns.
- 💩 The socket is `TlsClient`. `call` drops every non-`Response`.
- 💩 Idle time has no reader. `agent.run` sits in the TCP buffer.
- 💩 Osquery and `Command.stdout` also `call` on that socket.
  - A watch that stays up while `call` runs can steal the `Response`.
  - Osquery `call`s from a worker thread.
- 🚫 Do not switch the app socket to `OLLMrpc.Client` in this plan.
  - That type already demuxes notifications.
  - It also hellos, uses an async connect, and is unsafe from the osquery thread.
- 💩 The read belongs on `TlsClient` in OLLMchat.
  - Argus must not edit `libocrpc` from this tree.
  - Apply the library hunks in OLLMchat, install `ocrpc`, then the Argus hunks.

**Why:** `start` now pulls.

### `agent/Listen.vala` — `start`

**Why:** This is the pull the 2.0 stub left out.

**Where:** the whole `start` method.

**Depends on:** Phase 1.

#### Remove

```vala
		/**
		 * Watch the app socket for notifications.
		 *
		 * Returns without a read. The socket type has no call that
		 * yields a {@link OLLMrpc.Notification}.
		 */
		public void start()
		{
			GLib.debug("command notifications wait on the app socket");
		}
```

#### Replace with

```vala
		/**
		 * Watch the app socket for notifications.
		 *
		 * Connects {@link OLLMrpc.Transport.TlsClient.notification}
		 * to {@link notification} and starts {@link OLLMrpc.Transport.TlsClient.watch}.
		 */
		public void start()
		{
			this.link.notification.connect(this.notification);
			this.link.watch();
		}
```

- 🚫 Do not change `open_link` to `OLLMrpc.Client`.
