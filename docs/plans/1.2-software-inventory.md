## Purpose

- 🔷 `⏳` After identity, pull the list of software installed on the machine.

- 🔷 That catalog may be a git repository.
- 🔷 Server records follow osquery’s data to a large degree.
- ℹ️ Install and uninstall are [1.3](1.3-install-software.md) and [1.4](1.4-uninstall-software.md).
