## Purpose

- 🔷 The closed control shows the name of the filter that is on.
- 🔷 A custom filter is a dialogue of rule rows.

---

## Pull-down

- 🔷 The control sits at the left of the title action bar.
- 🔷 It lists the filters the user has saved.
- 🔷 Choosing one puts that name in the closed control, and the grid shows that filter.
- 🔷 With none chosen, the closed control shows that no filter is on, and the grid is the full list.
- 🔷 Opening it puts a search line above the names. The search narrows that list as it is typed.
- 🔷 Custom is the last entry. It opens the filter dialogue.

```
[ connected controllers v ]
+------------------------------+
| [ search                 ]   |
| connected controllers        |
| needs a package update       |
| Custom…                      |
+------------------------------+
```

---

## Filter dialogue

- 🔷 The dialogue edits one saved filter.
- 🔷 The filter has a name. Saving puts that name in the pull-down and applies it.
- 🔷 A rule row is a field, an operator, and a value.
- 🔷 The operators include equals and not equals.
- 🔷 A plus adds a row.
- 🔷 Each added row joins the one above it with and, or with or.
- 🔷 A connected machine is the same shape as any other field. Connected equals Yes. Connected not equals No.

```
+--------------------------------------------+
| Filter                                [x]  |
| name    [ connected controllers       ]    |
| [ Connected v ] [ equals     v ] [ Yes v ] |
| [ and v ]                                  |
| [ Kind      v ] [ equals     v ] [ Controller v ]
| [ + ]                                      |
|                              [ Save ]      |
+--------------------------------------------+
```

- 💩 Where a saved filter is kept. Decide that when there is a list worth filtering.
