## Phase 1

The bar sits on the page, under the Debian / RPM / Windows switcher and above the grid. The window header stays the title.

- ✔️ Three controls. A row stays when it passes all of them.
- ✔️ Search. An entry. It matches the package name.
- ✔️ Section. A multi-select, the same checkbox popover as the column menu.
  - One checkbox per section value in the loaded rows.
  - All start checked.
  - A checked section stays. The last checked section stays on.
  - A row whose section cell is a set stays when any of those sections is checked.
- 🔷 ⏳ Change. A plain dropdown, the same kind as Machines status. Any, and Recent changes. Not on the bar yet.
- 🔷 ⏳ Recent changes stays out of that dropdown until a change time is stored. The window length is not chosen.
- ✔️ Versions differ. A check on the bar.
  - On keeps rows whose min version and max version are not the same text.
  - That is the spread already shown as a red max-version cell.
  - It means the machines disagree. A package can be old on every machine and still have min equal max.
- ℹ️ `deb_packages` has no change time. First-seen is still open in [5.9.1](5.9.1-assets-software-data.md).
- ℹ️ Needs updating is [5.10](5.10-data-enrichment.md). This check is not that.
- ℹ️ The column menu is `controller/tab/Base.vala`. The Machines bar is `controller/tab/Asset/SystemInfo.vala`.

## Rubbish bin

- ✔️ The last column. The same bin as Windows. Installed moves left of it.
- ℹ️ Windows shows the icon when a machine has an uninstall string. `deb_packages` has no uninstall string.
- ✔️ The icon shows on every row that has an installed count. The mouseover is that count. Apt can remove an installed package, and the table does not say which ones are essential.
- 💩 ⏳ A click is the Remove task in [5.5](5.5-controller-user-interface.md). This plan does not run it.

## Later — secondary packages

- 🔷 A filter that hides the extra binaries of one source package.
- ℹ️ `source` is the source package name. dpkg leaves it empty when it equals the binary name. That empty value is what osquery stores.
- ℹ️ When one installed row is named the same as the source, that row is the namesake. The other rows with that source are the children, and those can be hidden.
- ℹ️ GTK 4 and GtkSourceView have no installed binary with the source's name.
  - Source `gtk4` is `libgtk-4-1`, `libgtk-4-common`, `libgtk-4-dev`, and the rest. None of them is named `gtk4`.
  - Source `gtksourceview5` is `libgtksourceview-5-0` and the rest. None of them is named `gtksourceview5`.
- ℹ️ The stored columns do not say which of those binaries is primary.
- 💩 Hide the children only when a namesake row is installed. A family with no namesake stays listed in full. That leaves GTK 4 and GtkSourceView uncollapsed.
- 🔷 ⏳ A rule that picks a primary inside a family with no namesake. Not phase 1.
