## Aims

- 🔷 **Audit the office.**
  - One picture of software across every managed machine.
  - What is installed, in the office, not on one desk.
  - How many machines have each thing.
  - Which versions are out there.
  - Which of those are behind.
  - Enough to see the estate, and how stale it is, without opening a machine.
  - A single machine is later, when you already know what you are looking at.
- 🔷 **Remove software that should not be there.**
  - Once it shows in that picture, it can come off.
  - The machine no longer has it.
  - You do not walk over and click uninstall.
- 🔷 **Notice what should not be happening.**
  - The office does not stay still after the audit.
  - An application appears that was not in the last picture.
  - An executable appears.
  - A socket opens that this kind of machine should not have.
  - You hear about it without walking the room.
- 🔷 **Keep Linux servers up to date.**
  - Those boxes do not drift.
  - The usual job is bring a server current, the way you would update it today.
  - Many servers, not one login each.
  - How that run is spelled is not this file.
  - The path is [1.2](1.2-aim-debian-update.md).
- 🔷 **Do the same work on many machines at once.**
  - One action, many agents.
  - A script, an update, a remove.
  - You do not repeat it machine by machine.
- 🔷 **See a server check fail, and put it right.**
  - The Nagios checks are scripts already on the boxes.
  - Their results show up here.
  - A bad result can be fixed with a script, on that box or on many.
  - The path is [8.0](8.0-nagios.md).
