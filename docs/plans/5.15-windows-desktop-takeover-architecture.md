# 5.15 — Windows Desktop Takeover Service Split

**Status:** ✔️ Agent implemented (1A + TrayServer split) — awaiting user verification.

ℹ️ Related bug/investigation: `docs/bugs/2026-11-26-ISSUE-windows-rdp-session-takeover.md`
ℹ️ Current placeholders: `agent/windows/Service.vala` (`relay_stop`, `relay_start`, `restart`)

## Purpose

- 🔷 `agent/windows/Service.vala` currently mixes three separate responsibilities (~750 lines at `HEAD`, ~860 lines now):
  1. `argus-agent` Windows SCM lifecycle (`start`, `service_main`, `control`, plus `--restart`)
  2. Local tray IPC server & `argus-tray.exe` supervision (`TcpListen`, `AgentService` RPCs, `agent.status` broadcasts, `tick()` launching `argus-tray.exe`)
  3. Remote desktop / relay (`desktop`, `relay_start`, `relay_stop`, `tunnel`)
- 🔷 Split along those coherent boundaries so each class has one clear job and `Service.vala` shrinks substantially instead of growing.

### Resulting class map & approximate sizes

| Class | Single responsibility | Size (with 1A) | Size (with 1B) |
| --- | --- | --- | --- |
| `agent/windows/Service.vala` | `argus-agent` Windows SCM lifecycle (`start`, `service_main`, `control`, `restart`) | ~520 lines (keeps `desktop` + `relay_*`) | ~260 lines (pure SCM + `desktop` retry) |
| `agent/windows/TrayServer.vala` | Everything for `argus-tray.exe`: `127.0.0.1:4142` `AgentService` RPCs (`hello`, `status`, `retry`, `register`, `initialize`, `allow`, `disconnect`), `agent.status` broadcasts, and `tick()` launching `argus-tray.exe` | ~360 lines | ~360 lines |
| `agent/windows/DesktopShare.vala` | Session-0 share host (`start`, `stop`, `poll_invite`, `spawn`) + Session-N COM worker (`run`) | ~290 lines | ~420 lines (+ `relay_start`/`relay_stop`/`tunnel`) |

## Decision 1: Session-0 sharing in `agent/windows/DesktopShare.vala` — ⏳ Awaiting approval

- 🔷 Target: `agent/windows/DesktopShare.vala` (4 methods added alongside existing `run()`):
  - `start(uint32 session, string data_dir)`
  - `stop()`
  - `poll_invite()` — helper method with early returns and flat/denested parsing
  - `spawn(...)` — `try/catch` narrowed to only the two `.to_utf16()` conversions
- ⏳ 💩 **Scope choice for existing relay code in `Service.vala`:**
  - **1A (minimal):** Keep `DesktopShare` to just the 4 methods below (emits `ready` / `failed`); leave existing `relay_start()` / `relay_stop()` in `Service.vala` (only replacing the two `// TODO` placeholders).
  - **1B (pull relay out of `Service.vala`):** Also move `relay_start()`, `relay_stop()`, and `tunnel` out of `Service.vala` into `DesktopShare.vala` (~150 more lines removed from `Service.vala`).

### Proposed changes — `agent/windows/DesktopShare.vala`

**Add** to `Argus.Agent.Windows.DesktopShare`:

```vala
		/**
		 * Emitted when the sharing worker is listening and has written its ticket.
		 *
		 * @param invite RACS2 connection string XML
		 * @param password one-time invitation password
		 * @param host local IP address the sharing session bound
		 * @param port TCP port the sharing session bound
		 */
		public signal void ready(string invite, string password, string host, uint16 port);

		/**
		 * Emitted when the sharing worker could not start or timed out.
		 */
		public signal void failed();

		private void* stop_event = null;
		private void* worker_proc = null;
		private string invite_file = "";
		private string share_pass = "";
		private uint16 chosen_port = 3399;
		private int64 poll_deadline = 0;
		private uint poll_id = 0;
		private int sequence = 0;

		/**
		 * Spawn the sharing worker in ''session'' and emit {@link ready} or {@link failed}.
		 *
		 * @param session active Windows session id
		 * @param data_dir agent data directory for the temporary invite file
		 */
		public void start(uint32 session, string data_dir)
		{
			this.stop();
			this.chosen_port = 3399;
			try {
				var probe = new GLib.SocketListener();
				GLib.SocketAddress? bound = null;
				var loopback = new GLib.InetSocketAddress(new GLib.InetAddress.loopback(GLib.SocketFamily.IPV4), 0);
				probe.add_address(loopback, GLib.SocketType.STREAM, GLib.SocketProtocol.TCP, null, out bound);
				this.chosen_port = ((GLib.InetSocketAddress) bound).get_port();
				probe.close();
			} catch (GLib.Error e) {
				GLib.warning("%s", e.message);
			}
			var alphabet = "ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz23456789";
			var pass_builder = new GLib.StringBuilder();
			for (var idx = 0; idx < 16; idx++) {
				pass_builder.append_c(alphabet[GLib.Random.int_range(0, alphabet.length)]);
			}
			this.share_pass = pass_builder.str;
			this.sequence++;
			var stop_name = "Global\\ArgusShareStop-%u-%d".printf(GetCurrentProcessId(), this.sequence);
			this.stop_event = CreateEventW(null, true, false, g_utf8_to_utf16(stop_name));
			this.invite_file = GLib.Path.build_filename(data_dir, "share-invite-%d.xml".printf(this.sequence));
			GLib.FileUtils.unlink(this.invite_file);
			if (!this.spawn(session, this.chosen_port, this.share_pass, this.invite_file, stop_name)) {
				this.stop();
				this.failed();
				return;
			}
			this.poll_deadline = GLib.get_monotonic_time() + 10 * 1000000;
			this.poll_id = GLib.Timeout.add(100, this.poll_invite);
		}

		/**
		 * Signal the sharing worker to stop and clean up handles and temp files.
		 */
		public void stop()
		{
			if (this.poll_id != 0) {
				GLib.Source.remove(this.poll_id);
				this.poll_id = 0;
			}
			if (this.stop_event != null) {
				SetEvent(this.stop_event);
				CloseHandle(this.stop_event);
				this.stop_event = null;
			}
			if (this.worker_proc != null) {
				WaitForSingleObject(this.worker_proc, 2000);
				TerminateProcess(this.worker_proc, 0);
				CloseHandle(this.worker_proc);
				this.worker_proc = null;
			}
			if (this.invite_file != "") {
				GLib.FileUtils.unlink(this.invite_file);
				this.invite_file = "";
			}
		}

		/**
		 * Poll for the worker's RACS2 invite XML and emit {@link ready} or {@link failed}.
		 *
		 * @return true while still waiting for the invite file, false once finished
		 */
		private bool poll_invite()
		{
			if (!GLib.FileUtils.test(this.invite_file, GLib.FileTest.EXISTS)) {
				var exited = this.worker_proc != null && WaitForSingleObject(this.worker_proc, 0) == WAIT_OBJECT_0;
				if (!exited && GLib.get_monotonic_time() < this.poll_deadline) {
					return true;
				}
				this.poll_id = 0;
				this.stop();
				this.failed();
				return false;
			}
			this.poll_id = 0;
			var invite = "";
			try {
				GLib.FileUtils.get_contents(this.invite_file, out invite);
			} catch (GLib.FileError e) {
				GLib.warning("%s", e.message);
			}
			GLib.FileUtils.unlink(this.invite_file);
			this.invite_file = "";
			if (invite == "") {
				this.stop();
				this.failed();
				return false;
			}
			var share_host = "127.0.0.1";
			var share_port = this.chosen_port;
			var l_pos = invite.index_of("<L ");
			if (l_pos < 0) {
				this.ready(invite, this.share_pass, share_host, share_port);
				return false;
			}
			var l_end = invite.index_of(">", l_pos);
			var tag = l_end > l_pos ? invite.substring(l_pos, l_end - l_pos) : invite.substring(l_pos);
			var p_pos = tag.index_of("P=\"");
			var p_end = p_pos >= 0 ? tag.index_of("\"", p_pos + 3) : -1;
			if (p_end > p_pos + 3) {
				share_port = (uint16) int.parse(tag.substring(p_pos + 3, p_end - p_pos - 3));
			}
			var n_pos = tag.index_of("N=\"");
			var n_end = n_pos >= 0 ? tag.index_of("\"", n_pos + 3) : -1;
			if (n_end > n_pos + 3) {
				share_host = tag.substring(n_pos + 3, n_end - n_pos - 3);
			}
			this.ready(invite, this.share_pass, share_host, share_port);
			return false;
		}

		/**
		 * Launch this executable as SYSTEM inside ''session'' with share flags.
		 *
		 * @param session target interactive session id
		 * @param port requested TCP port
		 * @param password one-time invitation password
		 * @param invite_path file path for the RACS2 XML
		 * @param stop_name named Win32 stop event
		 * @return true when the child process started
		 */
		private bool spawn(uint32 session, uint16 port, string password, string invite_path, string stop_name)
		{
			var exe = g_utf8_to_utf16(string.nfill(259, ' '));
			if (GetModuleFileNameW(null, exe, 260) == 0) {
				return false;
			}
			var exe_path = "";
			try {
				exe_path = exe.to_utf8();
			} catch (GLib.ConvertError e) {
				GLib.warning("%s", e.message);
				return false;
			}
			var slash = exe_path.last_index_of("\\");
			if (slash < 1) {
				return false;
			}
			void* self_tok = null;
			var access = TOKEN_DUPLICATE | TOKEN_QUERY | TOKEN_ASSIGN_PRIMARY | TOKEN_ADJUST_SESSIONID;
			if (!OpenProcessToken(GetCurrentProcess(), access, out self_tok)) {
				return false;
			}
			void* dup_tok = null;
			if (!DuplicateTokenEx(self_tok, MAXIMUM_ALLOWED, null, SecurityImpersonation, TokenPrimary, out dup_tok)) {
				CloseHandle(self_tok);
				return false;
			}
			CloseHandle(self_tok);
			var sid = session;
			if (!SetTokenInformation(dup_tok, TokenSessionId, (void*) (&sid), (uint32) sizeof(uint32))) {
				CloseHandle(dup_tok);
				return false;
			}
			var cmd = "\"%s\" --share-port %u --share-pass %s --share-invite \"%s\" --share-stop %s".printf(
				exe_path, port, password, invite_path, stop_name);
			string16 wide_cmd;
			string16 work_dir;
			try {
				wide_cmd = cmd.to_utf16();
				work_dir = exe_path.substring(0, slash).to_utf16();
			} catch (GLib.ConvertError e) {
				GLib.warning("%s", e.message);
				CloseHandle(dup_tok);
				return false;
			}
			var cmd_buf = new GLib.Array<uint16>();
			var cmd_len = wide_length(wide_cmd);
			for (var idx = (uint64) 0; idx < cmd_len; idx++) {
				var unit = wide_at(wide_cmd, idx);
				cmd_buf.append_val(unit);
			}
			var nul = (uint16) 0;
			cmd_buf.append_val(nul);
			var si = Win32.StartupInfo() {
				cb = (uint32) sizeof(Win32.StartupInfo),
				desktop = g_utf8_to_utf16("winsta0\\default"),
			};
			var info = ProcessInfo();
			var started = CreateProcessAsUserW(dup_tok, null, cmd_buf.data, null, null, false,
				CREATE_NO_WINDOW, null, work_dir, &si, out info);
			CloseHandle(dup_tok);
			if (started) {
				CloseHandle(info.thread);
				this.worker_proc = info.process;
			}
			return started;
		}
```

## Decision 2: Extract `agent/windows/TrayServer.vala` so `Service.vala` owns only `argus-agent` SCM (including `restart()`) — ⏳ Awaiting approval

- 🔷 Why this split is coherent:
  - `restart()` is literally part of the `argus-agent` Windows Service Control Manager lifecycle — it belongs next to `start()`, `service_main()`, and `control()` in `Service.vala`, NOT bundled with unrelated helpers like `enable_rdp()` or `ensure_tray()`.
  - What made `Service.vala` massive is that it also hosts the entire local `argus-tray.exe` IPC server (`AgentService` on `127.0.0.1:4142`), status broadcasting, registration RPC, and the `tick()` loop that launches `argus-tray.exe` in the active session (~360 lines).
  - Pulling **all tray-facing code** out of `Service.vala` into `agent/windows/TrayServer.vala`:
    - Gives `TrayServer.vala` one clear, coherent responsibility (~360 lines): local RPC server + tray supervision.
    - Brings `Service.vala` way down even WITH `Service.restart()` (~90 lines) restored in `Service.vala` (net **-270 lines** from `Service.vala` compared to today!).

### What moves from `agent/windows/Service.vala` into `agent/windows/TrayServer.vala`

- Fields: `local_listen`, `ticks`, `tray_connected` (public/internal `connected` property)
- Methods:
  - `start(Argus.Agent.Application application, Service service)` — registers `AgentService` on `OLLMrpc.Request`, starts `TcpListen("127.0.0.1", 4142)`, connects `application.state_changed` to broadcast `agent.status`, and starts the 1-second `tick()` timer
  - `stop()` — stops `local_listen`
  - `broadcast(OLLMrpc.Notification notif)` — forwards notifications (`agent.desktop`, `agent.desktop_active`) to connected tray clients
  - `rpc_register()` — registers `AgentService` (`hello`, `status`, `retry`, `register`, `allow`, `disconnect`) on `typeof(TrayServer)`
  - `hello()`, `status()`, `retry()`, `register()`, `initialize()` — moved verbatim from `Service.vala`
  - `allow()` / `disconnect()` — reply `"ok"` and call into `this.service` (or `DesktopShare` if 1B)
  - `tick()` — moved verbatim from `Service.vala` (checks for `argus-tray.exe` and launches it in the active user session)
- Build update: add `'windows/TrayServer.vala'` to `agent/meson.build`.

### What stays in `agent/windows/Service.vala`

- `start()` — `StartServiceCtrlDispatcherW`
- `service_main()` — SCM status reporting, starts `this.tray = new TrayServer(); this.tray.start(this.application, this);`, runs `this.application.run({ "argus-agent" })`, stops relay & tray on shutdown
- `control()` — `SERVICE_CONTROL_STOP`, `SERVICE_CONTROL_INTERROGATE`
- `restart()` — restores the ~90-line `argus-agent` SCM stop/kill/start routine (previously in `main.vala`), called by `Application.vala` on `--restart`:

```vala
		/**
		 * Stop and start the ''argus-agent'' Windows service elevated.
		 *
		 * Called by ''argus-agent --restart'' from the tray menu.
		 *
		 * @return 0 when the service is running again, non-zero Win32 error or 1
		 */
		public static int restart()
		{
			var scm = OpenSCManagerW(null, null, SC_MANAGER_CONNECT);
			if (scm == null) {
				var err = (int) GetLastError();
				return err != 0 ? err : 1;
			}
			var access = SERVICE_STOP | SERVICE_START | SERVICE_QUERY_STATUS;
			var svc = OpenServiceW(scm, g_utf8_to_utf16("argus-agent"), access);
			if (svc == null) {
				var err = (int) GetLastError();
				CloseServiceHandle(scm);
				return err != 0 ? err : 1;
			}
			var ssp = SERVICE_STATUS_PROCESS();
			var needed = (uint32) 0;
			var ssp_size = (uint32) sizeof(SERVICE_STATUS_PROCESS);
			if (!QueryServiceStatusEx(svc, SC_STATUS_PROCESS_INFO, (void*) (&ssp), ssp_size, (void*) (&needed))) {
				var err = (int) GetLastError();
				CloseServiceHandle(svc);
				CloseServiceHandle(scm);
				return err != 0 ? err : 1;
			}
			var stop_sent = false;
			for (var i = 0; i < 60; i++) {
				if (!QueryServiceStatusEx(svc, SC_STATUS_PROCESS_INFO, (void*) (&ssp), ssp_size, (void*) (&needed))) {
					break;
				}
				if (ssp.dwCurrentState == SERVICE_STOPPED) {
					break;
				}
				if (!stop_sent && ssp.dwCurrentState == SERVICE_RUNNING) {
					var ctrl = SERVICE_STATUS();
					if (ControlService(svc, SERVICE_CONTROL_STOP, ref ctrl)) {
						stop_sent = true;
					}
				}
				Sleep(250);
			}
			if (ssp.dwCurrentState != SERVICE_STOPPED && ssp.dwProcessId != 0) {
				var proc = OpenProcess(PROCESS_TERMINATE | SYNCHRONIZE, false, ssp.dwProcessId);
				if (proc != null) {
					TerminateProcess(proc, 1);
					WaitForSingleObject(proc, 5000);
					CloseHandle(proc);
				}
				for (var i = 0; i < 20; i++) {
					if (!QueryServiceStatusEx(svc, SC_STATUS_PROCESS_INFO, (void*) (&ssp), ssp_size, (void*) (&needed))) {
						break;
					}
					if (ssp.dwCurrentState == SERVICE_STOPPED) {
						break;
					}
					Sleep(250);
				}
			}
			if (ssp.dwCurrentState != SERVICE_STOPPED) {
				CloseServiceHandle(svc);
				CloseServiceHandle(scm);
				return 1;
			}
			if (!StartServiceW(svc, 0, null) && GetLastError() != ERROR_SERVICE_ALREADY_RUNNING) {
				var err = (int) GetLastError();
				CloseServiceHandle(svc);
				CloseServiceHandle(scm);
				return err != 0 ? err : 1;
			}
			for (var i = 0; i < 60; i++) {
				if (!QueryServiceStatusEx(svc, SC_STATUS_PROCESS_INFO, (void*) (&ssp), ssp_size, (void*) (&needed))) {
					break;
				}
				if (ssp.dwCurrentState == SERVICE_RUNNING) {
					CloseServiceHandle(svc);
					CloseServiceHandle(scm);
					return 0;
				}
				if (ssp.dwCurrentState == SERVICE_STOPPED) {
					break;
				}
				Sleep(250);
			}
			CloseServiceHandle(svc);
			CloseServiceHandle(scm);
			return 1;
		}
```
