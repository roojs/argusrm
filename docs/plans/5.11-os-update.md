## Purpose

- 🔷 Whether the installed OS release is current.
- 🔷 The server checks, once a week. A new release is the same fact for every machine on that release.
- ℹ️ Available packages are [5.10](5.10-data-enrichment.md). This plan is not that.
- ℹ️ Column names are [4.0](4.0-data-types.md).

---

## Shared

- 🔷 `os_version` stores `os_updated`. When the server last checked whether that OS release is current.
- 🔷 `os_version` stores `os_status`. The OS version is up to date. Not the installed packages.
- 🔷 The server writes both. Once a week. It reads the `os_version` name and version already stored.
- 🔷 The agent does not send `os_status`.
- 🔷 OS status on the machine list is `os_status`. [5.8](5.8-assets-page.md).
- ℹ️ These columns are not stored yet. Add them. There is no data to migrate.
- 💩 `os_updated` is the unix time, `0` when that check has not happened. `os_status` is `1` when up to date and `0` when not.
- 💩 Green when up to date, red when not. Empty when that check has not run.
- ℹ️ A family with no release file leaves `os_status` empty.
- 💩 Which date makes `os_status` `0` is not chosen. A later row whose `release` is already past, or an `eol` that has passed.

## Windows

- 🔷 ⏳ No release file yet. `os_status` stays empty until it exists.
- 🔷 `os_version` stores `reboot_required`. A restart is waiting.
- 🔷 The Windows agent sets `reboot_required` on the `os_version` row before the send.
- 🔷 The flag is `1` when either key is present, and `0` when neither is.
  - `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\WindowsUpdate\Auto Update\RebootRequired`
  - `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Component Based Servicing\RebootPending`
- 💩 The name is `reboot_required`. Confirm it before building.
- ℹ️ The agent reads those two keys. The `registry` table is not synced.
- ℹ️ Linux leaves `reboot_required` at `0`.

## LLM notes

- 🚫 Do not call the OS circle a package update. The OS circle is the OS version.
- 🚫 Do not have each agent check whether the OS release is current. The server does that, once a week.
- 🚫 Do not paint the OS circle from `update_available`. That read is [5.10](5.10-data-enrichment.md).
- 🚫 Do not paint the OS circle from `reboot_required`. That flag is a Windows restart waiting.
- 🚫 Do not invent a release list. A family with no file leaves `os_status` empty.
- 🚫 Do not sync the `registry` table. The Windows agent reads the two reboot keys onto `os_version`.
- 🚫 Do not build this before the data and the pages.
- 🚫 Do not mark a ✔️ line ✅.
