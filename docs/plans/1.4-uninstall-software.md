## Purpose

- 🔷 `⏳` A package that should not be on the machine can be removed quickly.
- 🔷 `⏳` Windows uninstall is vaguely standardised. Use that.
- ℹ️ The alert that something was installed is [1.5](1.5-monitor-and-notify.md). This plan is the removal.

---

## Removal

- 🔷 `⏳` Argus tells the agent which installed package to remove.
- 🔷 `⏳` The agent runs that package’s Windows uninstall.
- ℹ️ The usual entries are `QuietUninstallString` and `UninstallString` under the uninstall registry key.
- 💩 Prefer the quiet string when it is present. Confirm before build.
