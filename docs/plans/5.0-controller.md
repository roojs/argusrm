# 5.0 Controller CLI

**Status:** ✔️ applied in tree; await live `--pin` / `--agents` / `--command` against a running server

**Pointer:** `docs/guide-to-writing-plans.md` — **Checklist for plans**. Proposed Vala must follow `docs/coding-standards.md`.

**Parent:** [1.0-overview.md](1.0-overview.md), [3.0-server.md](3.0-server.md)

---

## Purpose

- ✔️ Command-line `argus-controller` only. No UI.
- ✔️ `--pin` opens the registration PIN. That is no longer the default with no arguments.
- ✔️ `Pin` in `controller/` owns that PIN behaviour.
- ✔️ `--agents` lists registered agents. An `Agents` class owns that.
- ✔️ `--agent ID` picks the machine. `--command` is the shell line, not the id.
- ✔️ `Command` runs that line on that agent and prints stdout and stderr.
- ⏳ `--pin`, `--agents`, and `--agent` / `--command` work against the local Unix socket.
- ℹ️ Remote run is [3.0 Phase 4](3.0-server.md) and [RPC commands](../rpc-commands.md).
- ℹ️ Controller enroll as a control client is [5.1-controller-registration.md](5.1-controller-registration.md).
- ✔️ Agent `Application.notification` reads `agent.run`. [2.4-listen.md](2.4-listen.md).

---

## Commands

- ✔️ No flag prints usage and exits `1`.
- ✔️ `--pin` — current PIN window. Class `Argus.Controller.Pin`.
- ✔️ `--agents` — no value. Class `Argus.Controller.Agents`.
- ✔️ `--agent ID` — `agent.id`. Required for a run.
- ✔️ `--command LINE` — the shell line. Class `Argus.Controller.Command`.
  - Leftover arguments after `--command` join onto that line.
  - Empty is an error.
- 💩 `--pin` and `--agents` are alone. `--agent` and `--command` go together.
- 💩 Each class is constructed with `app`. `run` takes no arguments. Flags are public statics on `Application`.
- 💩 `Application` opens the Unix client and hellos. The commands do not.
  - `argus.sock` under `Argus.SERVER_DATA_DIR`.
  - `{ live_handles = true }`.
  - Hello is `RPC-Daemon.hello` `is` `1`, `argus-controller`.

			OLLMrpc.rpc_register();

				return 1;
			}

			if (command != "") {
				parts.add(command);
			}
			parts.add_all_array(leftover[1:leftover.length]);
			if (!pin && !agents && parts.size < 1) {
				command_line.printerr("command needs --command\n");
				return 1;
			}
			command = string.joinv(" ", parts.to_array());
			this.cli = command_line;
			this.rpc = new OLLMrpc.Client("", "",
				GLib.Path.build_filename(Argus.SERVER_DATA_DIR, "argus.sock")) {
				live_handles = true
			};
			this.rpc.debug = false;
			this.loop = new GLib.MainLoop();
			this.code = 1;
			this.cli.print("Connecting to the local Argus server...\n");
			this.rpc.connect.begin(new OLLMrpc.Request() {
				method = "RPC-Daemon.hello",
				args = OLLMrpc.args("is", 1, "argus-controller")
			}, null, (obj, res) => {
				var opened = this.rpc.connect.end(res);
				if (!opened) {
					this.cli.printerr("%s\n", this.rpc.connect_error);
					this.loop.quit();
					return;
				}
				if (pin) {

				order.stdout.connect((text) => {
					this.cli.print("%s", text);
				});
				order.stderr.connect((text) => {
					this.cli.printerr("%s", text);
				});
				order.ended.connect(() => {
					this.code = 0;
					this.loop.quit();
				});
				order.run();
			});
			this.loop.run();
			return this.code;

**Why:** The user named this class for the current PIN window.

**Where:** new file.

**Depends on:** Phase 1 dispatch.

#### Add — new file `controller/Pin.vala`

```vala
namespace Argus.Controller
{
	/**
	 * Registration PIN on the command line.
	 *
	 * Creates a six-digit pin, prints it, and sends it with
	 * ''Agent.pair''. Sixty seconds later it sends an empty
	 * pin. {@link Application} already hellos.
	 *
	 * == Example ==
	 *
	 * {{{
	 * new Argus.Controller.Pin(app).run();
	 * }}}
	 */
	public class Pin : GLib.Object
	{
		public Application app;

		public Pin(Application app)
		{
			this.app = app;
		}

		/**
		 * Open the registration PIN.
		 */
		public void run()
		{
			var n = GLib.Random.int_range(0, 1000000);
			var pin = "%06d".printf(n);
			this.app.cli.print("Registration PIN: %s\nRegistration is open for 60 seconds. Press Ctrl+C to close it early.\n", pin);
			this.app.rpc.call.begin(new OLLMrpc.Request() {
				method = "Agent.pair",
				args = OLLMrpc.args("s", pin)
			}, (obj, res) => {
				try {
					var response = this.app.rpc.call.end(res);
					if (response.error != null) {
						this.app.cli.printerr("%s\n", response.error.message);
						this.app.loop.quit();
						return;
					}
					if (response.msg == "used") {
						this.app.cli.print("Registration PIN has been used.\n");
					}
				} catch (GLib.Error e) {
					this.app.cli.printerr("%s\n", e.message);
					this.app.loop.quit();
					return;
				}
				this.app.code = 0;
				this.app.loop.quit();
			});
			GLib.Timeout.add_seconds(60, () => {
				this.app.rpc.call.begin(new OLLMrpc.Request() {
					method = "Agent.pair",
					args = OLLMrpc.args("s", "")
				}, (obj, res) => {
					try {
						this.app.rpc.call.end(res);
					} catch (GLib.Error e) {
						GLib.warning("%s", e.message);
					}
				});
				return false;
			});
		}
	}
}
```

## Phase 4 — `--agent` / `--command`

- ✔️ `--agent` is `agent.id`. `--command` is the shell line.
- ✔️ Call `Command.run` `xo`: `agent.id`, then one `Argus.Command`.
- ✔️ `Command` emits `stdout`, `stderr`, and `ended`. It does not print.
- 💩 The CLI connects those signals to print and quit. A desktop later draws them.
- 💩 `identifier` is an `int`. A static starts at `1` and is incremented for each run. Notifications echo it. The listen path matches that id.
- 💩 Empty `environment` and `cwd` inherit the agent process.
- 💩 `Command.on_reply` is the `Command.run` callback. It does not quit.
- ✔️ The agent calls `Command.ended` when the child is dead.
- ✔️ The server then writes `controller.ended` on the controller that started the run.
- ✔️ That notification emits `ended`.
- ℹ️ The server already writes `agent.run` and later `controller.stdout` / `controller.stderr`.
- 💩 `⏳` Agent `Listen.start` must read those notifications or the run prints no output.

### `controller/Command.vala` — run a command

**Why:** The user named this class. It is also the outbound `Argus.Command` object.

**Where:** new file.

**Depends on:** Phase 1 `--agent` and leftover `--command`.

#### Add — new file `controller/Command.vala`

```vala
namespace Argus.Controller
{
	/**
	 * Run one command on a registered agent.
	 *
	 * The wire alias is ''Argus.Command''. {@link run} sends
	 * ''Command.run'' on the Unix socket. Notifications emit
	 * {@link stdout}, {@link stderr}, and {@link ended}.
	 * The CLI connects those. A desktop can draw them.
	 *
	 * == Example ==
	 *
	 * {{{
	 * var order = new Argus.Controller.Command(app);
	 * order.stdout.connect((text) => { });
	 * order.run();
	 * }}}
	 */
	public class Command : GLib.Object, OLLMrpc.Bin.Serializable
	{
		public Application app;
		public int identifier { get; set; default = 0; }
		private static int next_identifier = 1;
		public string command { get; set; default = ""; }
		public string[] environment { get; set; default = {}; }
		public string cwd { get; set; default = ""; }

		public signal void stdout(string text);
		public signal void stderr(string text);
		public signal void ended();

		public Command(Application app)
		{
			this.app = app;
		}

		/**
		 * Register the outbound command object.
		 */
		public static void rpc_register()
		{
			OLLMrpc.Bin.register("Argus.Command", typeof(Command));
		}

		/**
		 * Send the command.
		 */
		public void run()
		{
			var id = (int64) 0;
			if (!int64.try_parse(Application.agent, out id) || id < 1) {
				this.stderr("command needs an agent id\n");
				this.ended();
				return;
			}
			this.identifier = Command.next_identifier++;
			this.command = Application.command;
			this.app.rpc.notification.connect((notification) => {
				if (notification.args.size < 1) {
					return;
				}
				if (notification.args.get(0).get_int() != this.identifier) {
					return;
				}
				if (notification.method == "controller.ended") {
					this.ended();
					return;
				}
				if (notification.args.size < 2) {
					return;
				}
				var text = notification.args.get(1).get_string();
				if (notification.method == "controller.stdout") {
					this.stdout(text);
					return;
				}
				if (notification.method == "controller.stderr") {
					this.stderr(text);
				}
			});
			this.app.rpc.call.begin(new OLLMrpc.Request() {
				method = "Command.run",
				args = OLLMrpc.args("xo", id, this)
			}, this.on_reply);
		}

		/**
		 * Take the ''Command.run'' reply.
		 *
		 * @param rpc the Unix client
		 * @param res the finished call
		 */
		public void on_reply(GLib.Object? rpc, GLib.AsyncResult res)
		{
			try {
				var response = this.app.rpc.call.end(res);
				if (response.error != null) {
					this.stderr(response.error.message + "\n");
					this.ended();
				}
			} catch (GLib.Error e) {
				this.stderr(e.message + "\n");
				this.ended();
			}
		}
	}
}
```

#### Add — `ended` on `Command`

```vala
		/**
		 * Tell the controller the child is dead.
		 *
		 * @param request inbound RPC from the agent
		 * @param identifier {@link Command.identifier} of the run
		 */
		public void ended(OLLMrpc.Request request, int identifier)
		{
			if (Command.agents == null || !Command.agents.has_key(identifier)) {
				request.reply(new OLLMrpc.Response() {
					error = new OLLMrpc.Error(
						(int) OLLMrpc.RpcErrorCode.INVALID_REQUEST,
						"unknown command"
					)
				});
				return;
			}
			var caller = request.connection as SslConnection;
			if (caller == null || caller.agent_id != Command.agents.get(identifier).agent_id) {
				request.reply(new OLLMrpc.Response() {
					error = new OLLMrpc.Error(
						(int) OLLMrpc.RpcErrorCode.INVALID_REQUEST,
						"unknown command"
					)
				});
				return;
			}
			if (Command.controllers != null && Command.controllers.has_key(identifier) && Command.controllers.get(identifier).running) {
				Command.controllers.get(identifier).write(new OLLMrpc.Notification() {
					method = "controller.ended",
					args = OLLMrpc.args("i", identifier)
				});
			}
			request.reply(new OLLMrpc.Response() {
				msg = "ok"
			});
		}
```
