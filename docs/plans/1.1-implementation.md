## Where we are now

- ✔️ Agent, server, and controller build and install.
- ✔️ A machine can enroll. PIN, certificate, Linux service.
- ✔️ Osquery installs and posts identity.
- ✔️ `argus-controller --agent ID --command` runs one line on one agent and prints the output.

## Options for next

- 🔷 Prefer easy wins.
  - 🔷 The base can be done on every platform.
  - 🔷 Windows is closer for getting that base up and running.
  - 🔷 Security is later.
- 🔷 **Tasks.**
  - 🔷 The core activity. A command on a machine, with more around it.
  - ℹ️ Schema is [7.0-tasks.md](7.0-tasks.md). Steps are [7.1-tasks-implementation.md](7.1-tasks-implementation.md).
  - 🔷 The controller easy win is the Scripts page. Those RPCs are ready. [5.5](5.5-controller-user-interface.md).
- 🔷 **Repository syncing.**
  - 🔷 A local SQLite list of available repositories.
  - 🔷 Pull, or run a pull request, on a folder on a remote server.
  - 🔷 Sync that list with a sister Argus.
  - ℹ️ MTrack already does remote pull requests using Argus.
  - ℹ️ Last pulled commit, and stale checkouts on a machine, live here. Not the script library on this server. That is [7.0](7.0-tasks.md).
- 🔷 **Agent packaging.**
  - 🔷 Not until the agent can do something. Tasks first.
  - ℹ️ [2.1.5-installation-packaging.md](2.1.5-installation-packaging.md).
- 🔷 **Office-wide software picture.**
  - 🔷 An osquery task, then a process that stores the output.
  - 🔷 A UI that shows that picture.
  - 🔷 Controller UI. The pages and the aim flows are [5.5](5.5-controller-user-interface.md).
  - 🔷 Sign-in on the controller.
  - 🔷 Sign-in on the server.
- 🔷 **Linux server updates.**
  - 🔷 A task: a script that brings the box current, on many machines.
  - 🔷 The controller path filters those machines and runs the package manager on them. [5.5](5.5-controller-user-interface.md).
  - 🔷 Needs the agent on public servers, and that sign-up flow.
  - ℹ️ The live path, and registration by IP address, are [1.2](1.2-aim-debian-update.md).
- 🔷 **Take software off a machine.**
  - 🔷 A task: a script that runs the uninstall.
- 🔷 **Nagios checks.**
  - 🔷 Run the check scripts already on the servers. Keep the output. A bad result runs a fix script.
  - ℹ️ [8.0](8.0-nagios.md). It is a task, so the task work comes first.

### Later — security

- 🔷 iptables on public Linux servers. Not a Windows need yet.
- 🔷 PIN and elevation, once that access is public.
- 🔷 Notice new applications, executables, or sockets.
  - 🔷 Event monitoring on the agent.
  - 🔷 A filter database on the agent, replicated from the server.
  - 🔷 The agent only sends events that pass that filter.
  - 🔷 The server monitors those events.
- ℹ️ iptables is [3.0-server.md](3.0-server.md). PIN is [2026-11-04-elevation-dialog-and-pin-used.md](../bugs/2026-11-04-elevation-dialog-and-pin-used.md).
