## Purpose

- 🔷 `⏳` A controller can add a catalog package to a machine that does not have it.
- 🔷 `⏳` Install is a download, then an install.
- 🔷 `⏳` Argus manages the download space.
- 🔷 `⏳` Argus can fetch a package from an online source and then offer it.
- 🔷 `⏳` The agent downloads a set of files on the download socket and runs the install.
- 🔷 `⏳` Those bytes stay off the main app socket.
- 🔷 `⏳` Setup may include install scripts.
- ℹ️ The file hand-out used for the osquery installer is [1.1](1.1-enroll-desktop.md).

---

## Server files

- 🔷 `⏳` Argus stores the files for a package.
- 🔷 `⏳` Argus can download those files from an online resource into that store.
- 💩 How much disk, and whether a fetch is a Pman process. Confirm before build.
- ℹ️ A little of the Pman process track is in [0-overview.md](0-overview.md).

---

## Agent install

- 🔷 `⏳` The controller picks the package.
- 🔷 `⏳` The agent downloads the file set from Argus on the download socket.
- 🔷 `⏳` The agent runs the install, including any install script for that package.
