## Purpose

- 🔷 `⏳` Watch for installed application changes.
- 🔷 `⏳` A new program that should not be there warns quickly.
- 🔷 The example is a staff member installing a ChatGPT desktop client.
- 🔷 `⏳` The agent tells Argus. Argus raises a warning.
- 🔷 `⏳` A cron or shell script asks Argus whether any warning is open, so Nagios can show it.
- 🔷 `⏳` The same warning can be broadcast to Android phones that have the app.
- 🔷 Port checks are later. Something using a port other than the one expected. That is osquery data.
- ℹ️ Removal of the package is [1.4](1.4-uninstall-software.md).
- ℹ️ Existing Nagios check scripts: `server.media-outreach/etc/nagios/`.

---

## Application changes

- 🔷 `⏳` The agent notices a new or removed program and reports it.
- 🔷 `⏳` Argus keeps that as a warning a controller can see.
- 💩 How often the agent compares the program list. Confirm before build.

---

## Nagios

- 🔷 `⏳` A shell script on a timer queries Argus for open warnings.
- 🔷 `⏳` Nagios shows the result.
- 💩 Argus is queried by that script. It is not itself a Nagios plugin host. Confirm before build.

---

## Phones

- 🔷 `⏳` Registered Android controllers receive the warning.

---

## Ports

- 🔷 `⏳` Later: warn when a port in use is not the expected one.
- ℹ️ This waits on osquery. It is not part of the first warning.
