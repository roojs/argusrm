## Purpose

- 🔷 Phase 3 of [5.10](../5.10-DONE-data-enrichment.md). The agent sends the package names that need updating. The server sets `update_available`, `pkgs_status`, and `pkgs_updated`.
- 🔷 Prerequisite: [2026-11-13-agent-user-refactor.md](../../bugs/done/2026-11-13-FIXED-agent-user-refactor.md) (`Argus.Shared.Agent.user`, `SslConnection.user`, and `Argus.Shared.Agent.notify_controllers`).
- 🔷 Two calls. One is the RPM names. One is the deb names. Each argument is a string array.
- 🔷 Not one call. The two payloads are the same shape. They stay separate.
- 🔷 The methods are `DebPackages.send_pending` and `RpmPackages.send_pending` (and `PackageMonitor.send_pending` on the agent).
- 🔷 Each handler updates the stored package rows with bulk SQL `UPDATE` statements (`SET update_available = 0` with `NOT IN` and `SET update_available = 1` with `IN` using prepared-statement `?` placeholders, prepared together and bound in a single loop) rather than fetching rows and looping.
- 🔷 When packages need updating (`kept.length > 0`), the server sends an RPC notification to connected controllers (`event.packages` / `pending`, carrying `agent.id`) so controllers know that machine needs updating.
- ℹ️ The read is `UpdatesAvailable.check`. APT and DNF. [5.10](../5.10-DONE-data-enrichment.md) Phase 2.
- ℹ️ An install or a removal stays `OSQuery.sync`. [5.9.1](5.9.1-DONE-assets-software-data.md).

---

## Calls

- 🔷 Socket: the app socket. The client certificate selects the machine. The agent id is not an argument.
- 🔷 Direction: the agent calls the server.
- 🔷 Arguments `as` (`S` in `Request.add_class` for Vala `string[]` length): the package names `check` returned.
- 🔷 An empty array means nothing needs updating.
- 🔷 A failure from `check` is not sent. An empty array would mean up to date.
- 🔷 APT sends `DebPackages.send_pending`. DNF sends `RpmPackages.send_pending`.
- 🔷 Windows does not send. Android does not send. SUSE is `UNKNOWN` and does not send.
- 🔷 When packages need updating, the server notifies controllers via an RPC notification (`event.packages` / `pending`).
- 💩 Reply `msg`: `ok`. No return value.
- 💩 A controller caller receives `agent only`. An invalid or deleted certificate throws from `Agent.user` up to the connection level ([2026-11-13-agent-user-refactor.md](../../bugs/done/2026-11-13-FIXED-agent-user-refactor.md)).
- ℹ️ `docs/rpc-commands.md` gains both calls and the notification in the same change.

Edits are **Remove** / **Replace with** / **Add** from the tree. Verify the surrounding lines before applying.

## Server

- 🔷 `DebPackages.send_pending` and `RpmPackages.send_pending` resolve the caller via `Argus.Shared.Agent.user(request)` and declare `throws GLib.Error` without catching caller errors locally ([2026-11-13-agent-user-refactor.md](../../bugs/done/2026-11-13-FIXED-agent-user-refactor.md)).
- 🔷 The agent does not send `update_available`, `pkgs_status`, or `pkgs_updated`. The server writes them.
- 🔷 Bulk SQL `UPDATE` statements on the package table clear `update_available = 0` where `agent_id = ? AND deleted_dt = 0` and `name NOT IN (?, ...)` (or all live rows when the list is empty), then set `update_available = 1` where `agent_id = ? AND deleted_dt = 0 AND name IN (?, ...)`, preparing both statements together and binding package names in one loop. It does not fetch rows or loop `updateById`.
- 🔷 When `kept.length > 0`, the server sends an `OLLMrpc.Notification` (`method = "event.packages"`, `action = "pending"`, `args = OLLMrpc.args("i", (int) agent.id)`) to connected controllers via `Argus.Shared.Agent.notify_controllers`.
- 🔷 The read is the package name. APT's second field. DNF's name with the arch removed. Every stored arch of that name is set.
- 🔷 A name that is not already stored is left out. This call does not insert a package.
- 💩 A row with `deleted_dt` set is left alone.
- 💩 `updated_dt` stays. The flag is not a package change.
- 💩 One SQL `UPDATE` on `os_version` writes `pkgs_updated` as the unix time of this call and `pkgs_status` as `1` when no name is waiting and `0` when one is.
- 💩 A blank name in the array is left out. It does not count as waiting.
- 💩 The call backs up the database, the same as `OSQuery.sync`.

Edits are **Remove** / **Replace with** / **Add** from the tree. Verify the surrounding lines before applying.

#### Add — after `list`, the handler

The method follows the closing brace of `list`.

```vala
		/**
		 * Store which Debian packages have an update waiting.
		 *
		 * The agent calls this on the app socket.
		 * {@link Argus.Shared.Agent.user} resolves the certificate.
		 * ''names'' clears ''update_available'' on live
		 * ''deb_packages'' rows not in the list and sets it on rows
		 * in the list. ''pkgs_updated'' becomes the time of this
		 * call, and ''pkgs_status'' is up to date when none wait.
		 * When packages are waiting, connected controllers receive
		 * ''event.packages''.
		 *
		 * @param request inbound RPC on the app socket
		 * @param names package names that need updating
		 * @throws GLib.Error when no active caller row exists
		 */
		public void send_pending(OLLMrpc.Request request, string[] names) throws GLib.Error
		{
			var agent = Argus.Shared.Agent.user(request);
			if (agent.is_controller) {
				request.reply(new OLLMrpc.Response() {
					error = new OLLMrpc.Error.INVALID_REQUEST("agent only")
				});
				return;
			}
			string[] kept = {};
			foreach (var name in names) {
				if (name == "") {
					continue;
				}
				kept += name;
			}
			var packages = new SQ.Query<DebPackages>(DebPackages.db, "deb_packages");
			if (kept.length == 0) {
				var clear_stmt = packages.selectPrepare("""
					UPDATE
						deb_packages
					SET
						update_available = 0
					WHERE
						agent_id = ?
					AND
						deleted_dt = 0
					""");
				clear_stmt.bind_int64(1, agent.id);
				DebPackages.db.db_mutex.lock();
				if (Sqlite.DONE != clear_stmt.step()) {
					GLib.warning("deb_packages update failed: %s", DebPackages.db.db.errmsg());
				}
				DebPackages.db.db_mutex.unlock();
			}
			if (kept.length > 0) {
				var placeholders = "?" + string.nfill(kept.length - 1, 'X').replace("X", ", ?");
				var clear_stmt = packages.selectPrepare("""
					UPDATE
						deb_packages
					SET
						update_available = 0
					WHERE
						agent_id = ?
					AND
						deleted_dt = 0
					AND
						name NOT IN (%s)
					""".printf(placeholders));
				var mark_stmt = packages.selectPrepare("""
					UPDATE
						deb_packages
					SET
						update_available = 1
					WHERE
						agent_id = ?
					AND
						deleted_dt = 0
					AND
						name IN (%s)
					""".printf(placeholders));
				clear_stmt.bind_int64(1, agent.id);
				mark_stmt.bind_int64(1, agent.id);
				for (var i = 0; i < kept.length; i++) {
					clear_stmt.bind_text(i + 2, kept[i]);
					mark_stmt.bind_text(i + 2, kept[i]);
				}
				DebPackages.db.db_mutex.lock();
				if (Sqlite.DONE != clear_stmt.step()) {
					GLib.warning("deb_packages update failed: %s", DebPackages.db.db.errmsg());
				}
				if (Sqlite.DONE != mark_stmt.step()) {
					GLib.warning("deb_packages update failed: %s", DebPackages.db.db.errmsg());
				}
				DebPackages.db.db_mutex.unlock();
			}
			var version_stmt = packages.selectPrepare("""
				UPDATE
					os_version
				SET
					pkgs_updated = ?,
					pkgs_status = ?
				WHERE
					agent_id = ?
				AND
					deleted_dt = 0
				""");
			version_stmt.bind_int64(1, new GLib.DateTime.now_utc().to_unix());
			version_stmt.bind_int(2, kept.length == 0 ? 1 : 0);
			version_stmt.bind_int64(3, agent.id);
			DebPackages.db.db_mutex.lock();
			if (Sqlite.DONE != version_stmt.step()) {
				GLib.warning("os_version update failed: %s", DebPackages.db.db.errmsg());
			}
			DebPackages.db.db_mutex.unlock();
			DebPackages.db.backupDB();
			if (kept.length > 0) {
				Argus.Shared.Agent.notify_controllers(new OLLMrpc.Notification() {
					method = "event.packages",
					action = "pending",
					args = OLLMrpc.args("i", (int) agent.id)
				});
			}
			request.reply(new OLLMrpc.Response() {
				msg = "ok"
			});
		}
```

## Agent

- 🔷 The check runs twice a day. Twelve hours.
- 🔷 `PackageMonitor.start` already chooses APT or DNF. That is where the send starts. The file watch stays the install and the removal.
- 💩 The first check runs when `start` runs. The twelve-hour timer repeats it. A new host would otherwise stay at `pkgs_updated` `0` for half a day.
- 💩 The timer id is `pending_id` on `PackageMonitor`.
- ℹ️ The desktop agent and the command-line agent both compile `agent/linux/PackageMonitor.vala`.
- ℹ️ `Win32/PackageMonitor.vala` does not gain this. `check` there throws.

Edits are **Remove** / **Replace with** / **Add** from the tree. Verify the surrounding lines before applying.

		 * Start the watch this host uses, then the update check.
		 *
		 * {@link Application.os_version} is the startup osquery
		 * row. {@link Argus.Shared.OSQuery.OsVersion.package_manager}
		 * chooses the watch. APT calls {@link apt}. DNF calls
		 * {@link rpm}. Either one then calls {@link send_pending}
		 * and repeats that every twelve hours. Any other value
		 * returns.
		 */
		public void start()
		{
			switch (this.application.os_version.package_manager()) {
				case Argus.Shared.OSQuery.PackageManager.APT:
					this.apt();
					break;

				case Argus.Shared.OSQuery.PackageManager.DNF:
					this.rpm();
					break;

				default:
					return;
			}
			this.send_pending();
			this.pending_id = GLib.Timeout.add_seconds(12 * 60 * 60, () => {
				this.send_pending();
				return true;

		 * Post the names that need updating.
		 *
		 * {@link UpdatesAvailable.check} reads the host. A failure
		 * is not sent. An empty list is up to date. APT posts
		 * ''DebPackages.send_pending''. DNF posts
		 * ''RpmPackages.send_pending''.

		public void send_pending()
		{
			var names = new Gee.ArrayList<string>();
			try {
				names = new UpdatesAvailable().check(this.application.os_version);
			} catch (GLib.Error e) {
				GLib.warning("%s", e.message);
				return;
			}
			if (this.application.connection == null) {
				GLib.warning("server connection is not open");
				return;
			}
			var call_name = "";
			switch (this.application.os_version.package_manager()) {
				case Argus.Shared.OSQuery.PackageManager.APT:
					call_name = "DebPackages.send_pending";
					break;

				case Argus.Shared.OSQuery.PackageManager.DNF:
					call_name = "RpmPackages.send_pending";
					break;

				default:
					return;
			}
			try {
				var response = this.application.connection.call(new OLLMrpc.Request() {
					method = call_name,
					args = OLLMrpc.args("as", names.to_array())
				});
				if (response.error != null) {
					GLib.debug("send_pending failed %s", response.error.message);
				}
			} catch (GLib.Error e) {
				Application.connection_down = true;
				GLib.warning("%s", e.message);
			}
		}

## LLM notes

- 🚫 Do not implement this plan before [2026-11-13-agent-user-refactor.md](../../bugs/done/2026-11-13-FIXED-agent-user-refactor.md) lands.
- 🚫 Do not use one call for both classes. The payloads are both string arrays. The calls stay two.
- 🚫 Do not send the names through `OSQuery.sync`. A row left out of that call is marked deleted.
- 🚫 Do not select package rows and loop `updateById` in `send_pending`, and do not interpolate values into SQL. Use prepared `UPDATE` statements (`SET update_available = 0 ... name NOT IN (?, ...)` and `SET update_available = 1 ... name IN (?, ...)`).
- 🚫 Do not inline the fingerprint SQL query in `send_pending` or catch `Agent.user` errors locally — declare `throws GLib.Error` and let them reach the connection level.
- 🚫 Do not have the agent set `update_available`, `pkgs_status`, or `pkgs_updated`.
- 🚫 Do not send when `check` throws. That is not an empty list.
- 🚫 Do not insert a package from a name that is not stored.
- 🚫 Do not add `send_pending` to `Programs`. Windows has no list.
- 🚫 Do not run the update. The lists are already on the host.
