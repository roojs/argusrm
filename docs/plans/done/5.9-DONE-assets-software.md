## Columns

Three grids. Each grid is that sub-tab's table, one row per name. The stored table stays one row per machine.

- ✅ starts visible.
- hidden starts off, and can be turned on.
- ℹ️ A tick here is the display choice.
- 🔷 Each grid's row key is the name in that table.
- 🔷 Installed is the quantity. The number of machines that name is installed on.
- 🔷 Installed is the rightmost column on the Debian grid and the RPM grid.
- 🔷 On Windows the rubbish bin is the last column. The icon shows when any machine with that package has an uninstall string. The mouseover is how many of those machines are uninstallable.
- 🔷 Min version and max version are columns. They are the spread of the stored `version` for that name.
- 🔷 A machine that has not had the OS upgrade is behind the latest. Min and max show that gap.
- 🔷 When min version and max version differ, the max version cell is a red background with white text.

### Debian

`deb_packages`. The Debian sub-tab. One installed package. Stored.

- ✅ `name` — package name. The row key.
- ✅ `arch` — the architectures in use. amd64, all.
- ✅ `section` — archive section. The category. `httpd`, `libs`, `admin`. The same across those machines.
- ✅ `priority` — required, important, standard, optional, extra. The same. Unlikely to differ.
- ✅ Min version. The lowest `version` for that name, suffixed with the lowest `revision` for that version. The header is Min version.
- ✅ Max version. The highest `version` for that name, suffixed with the highest `revision` for that version. The header is Max version.
- ✅ Max size. The largest `size` for that name. The header is Max size.
- ✅ Installed. The quantity. How many machines that name is installed on. A count. The header is Installed. Rightmost until the remove column in [5.9.2.1](5.9.2.1-DONE-debian-filters-phase1.md).
- hidden `source` — source package name. Not the main list. The same kind of value as the name, so it can be turned on.
- hidden `maintainer` — the maintainer string. Hidden. It can be turned on.

### RPM

`rpm_packages`. The RPM sub-tab. One installed RPM. Stored.

- ✅ `name` — package name. The row key.
- ✅ `arch` — the architectures in use. x86_64, noarch.
- ✅ `package_group` — the category. `System Environment/Daemons`.
- ✅ Min version. The lowest `epoch`, `version`, and `release` for that name. The cell is `epoch:version-release`. The header is Min version.
- ✅ Max version. The highest `epoch`, `version`, and `release` for that name. The cell is `epoch:version-release`. The header is Max version.
- ✅ Max size. The largest `size` for that name. The header is Max size.
- ✅ Installed. The quantity. How many machines that name is installed on. A count. The header is Installed. Rightmost.
- hidden `source` — source RPM name.
- hidden `vendor` — the vendor string.

### Windows

`programs`. The Windows sub-tab. One installed program. Stored. This grid has no size column.

- ✅ `name` — program name. The row key.
- ✅ `publisher` — the publisher.
- ✅ Min version. The lowest `version` for that name. The header is Min version.
- ✅ Max version. The highest `version` for that name. The header is Max version.
- ✅ Installed. The quantity. How many machines that name is installed on. A count. The header is Installed.
- ✅ Uninstall. The last column. A rubbish bin when any machine with that name has an `uninstall_string`. The mouseover is how many of those machines are uninstallable.
- hidden `language` — language.
- hidden `identifying_number` — the product code.
- hidden `install_date` — when it was installed.
- hidden `install_location` — where the files are.
- hidden `install_source` — where it was installed from.
- hidden `uninstall_string` — the uninstall command. The text stays hidden. The icon is the Uninstall column.
