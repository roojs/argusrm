## Purpose

- 🔷 Phase 2 of [5.11](5.11-REJECTED-os-update.md). The server checks stored `os_version` rows once a week and writes `os_updated` and `os_status`.
- 🔷 Only fetch release CSVs for platforms actually present in active `os_version` rows (`deleted_dt = 0` and `agent_id` in `agent`).
- 🔷 `os_version.os_updated` records when we last fetched. No separate store or table tracks fetch times.
- ℹ️ Column names and sync are Phase 1 of [5.11](5.11-REJECTED-os-update.md).

---

## Server weekly check

- 🔷 A platform whose active rows were all checked within the last seven days is not fetched again.
- ℹ️ A family with no release file leaves `os_updated` at `0` and `os_status` empty.
- 💩 `row.platform` selects the file: `debian`, `ubuntu`, or `elxr`. `platform_like` is not used here because Ubuntu and eLxr both report `debian`.
- 💩 `OsUpdate.start` runs one check at startup and repeats every hour. When nothing is due (`os_updated > now - 7 days`), the check is an in-memory query only and makes no HTTP request.
- 💩 `OSQuery.sync` triggers `os_update.check.begin()` when `OsVersion` arrives so a newly registered machine with `os_updated == 0` is checked without waiting for the timer.
- 💩 Each row matches the CSV by `codename` against `series`, or by `version` prefix when `codename` is empty.
- 💩 Which date makes `os_status` `0`: a later row whose `release` is on or before today, or an `eol` before today. Confirm before building.

### Debian

- 🔷 The weekly read is `https://debian.pages.debian.net/distro-info-data/debian.csv`.
- ℹ️ A row is one release. Columns are `version`, `codename`, `series`, `created`, `release`, `eol`, `eol-lts`, and `eol-elts`. No `release` date means it is not out yet.

### Ubuntu

- 🔷 The weekly read is `https://debian.pages.debian.net/distro-info-data/ubuntu.csv`.
- ℹ️ The Debian columns, plus `eol-server`, `eol-esm`, and `eol-legacy`. Future rows carry a future `release` date.
- 💩 Under the later-row rule, an LTS row such as `26.04 LTS` becomes `0` once `26.10` is released unless LTS rows compare only against later `LTS` rows.

### eLxr

- 🔷 The weekly read is `https://debian.pages.debian.net/distro-info-data/elxr.csv`.
- ℹ️ Columns stop at `eol`. The file has `12` aria and `26.04` bianca.

### Fedora, RHEL, CentOS, SUSE, Android

- 🔷 ⏳ No release file yet. `os_status` stays empty until it exists.
- ℹ️ `reboot_required` stays `0` on Linux and Android.

Edits are **Remove** / **Replace with** / **Add** from the tree. Verify the surrounding lines before applying.

### 1. `server/OsUpdate.vala` — weekly check of stored `os_version` rows

**Why:** check only the OS platforms stored in `os_version` whose `os_updated` is `0` or at least seven days old, and store the fetch time on those rows.

**Where:** new file in `server/`.

**Depends on:** [5.11](5.11-REJECTED-os-update.md) Phase 1.

#### Add — new file `server/OsUpdate.vala`

```vala

namespace Argus.Server
{
	/**
	 * Weekly check of stored ''os_version'' releases.
	 *
	 * {@link check} inspects active ''os_version'' rows. Only
	 * platforms present in that table with ''os_updated'' unset or
	 * at least seven days old are fetched. Each fetched CSV updates
	 * ''os_updated'' and ''os_status'' on every active row of that
	 * platform.
	 *
	 * == Example ==
	 *
	 * {{{
	 * var os_update = new Argus.Server.OsUpdate(app);
	 * os_update.start();
	 * }}}
	 */
	public class OsUpdate : GLib.Object
	{
		/**
		 * Server that owns the database.
		 */
		public Application app { get; private set; }

		private uint source_id = 0;
		private bool checking = false;

		/**
		 * Create the checker for one server.
		 *
		 * @param app the running server
		 */
		public OsUpdate(Application app)
		{
			Object();
			this.app = app;
		}

		/**
		 * Run the first check and repeat hourly for due rows.
		 */
		public void start()
		{
			if (this.source_id != 0) {
				return;
			}
			this.check.begin();
			this.source_id = GLib.Timeout.add_seconds(60 * 60, () => {
				this.check.begin();
				return true;
			});
		}

		/**
		 * Cancel the repeating timer.
		 */
		public void stop()
		{
			if (this.source_id != 0) {
				GLib.Source.remove(this.source_id);
				this.source_id = 0;
			}
		}

		/**
		 * Fetch due ''distro-info-data'' files and write
		 * ''os_updated'' and ''os_status''.
		 */
		public async void check()
		{
			if (this.checking) {
				return;
			}
			this.checking = true;
			var query = new SQ.Query<Argus.Shared.OSQuery.OsVersion>(
				this.app.db, "os_version");
			var stored = new Gee.ArrayList<Argus.Shared.OSQuery.OsVersion>();
			query.select(
				"WHERE deleted_dt = 0 AND agent_id IN (SELECT id FROM agent)",
				stored);
			var cutoff = (int) new GLib.DateTime.now_utc().to_unix() - (7 * 24 * 60 * 60);
			var urls = new Gee.HashMap<string, string>();
			foreach (var row in stored) {
				if (row.os_updated > 0 && row.os_updated > cutoff) {
					continue;
				}
				switch (row.platform) {
					case "debian":
						urls.set("debian",
							"https://debian.pages.debian.net/distro-info-data/debian.csv");
						break;

					case "ubuntu":
						urls.set("ubuntu",
							"https://debian.pages.debian.net/distro-info-data/ubuntu.csv");
						break;

					case "elxr":
						urls.set("elxr",
							"https://debian.pages.debian.net/distro-info-data/elxr.csv");
						break;

					default:
						break;
				}
			}
			if (urls.size == 0) {
				this.checking = false;
				return;
			}
			var session = new Soup.Session();
			var today = new GLib.DateTime.now_utc().format("%Y-%m-%d");
			var changed = false;
			foreach (var entry in urls.entries) {
				var message = new Soup.Message("GET", entry.value);
				message.request_headers.append("User-Agent", "argusrm");
				var body = new GLib.Bytes(new uint8[0]);
				try {
					body = yield session.send_and_read_async(
						message, GLib.Priority.DEFAULT, null);
				} catch (GLib.Error e) {
					GLib.warning("%s", e.message);
					continue;
				}
				if (message.status_code != 200 || body.get_size() == 0) {
					GLib.warning("os release %s %u", entry.key, message.status_code);
					continue;
				}
				string[] versions = {};
				string[] series_list = {};
				string[] eols = {};
				var latest = -1;
				var header = true;
				foreach (var raw in ((string) body.get_data()).substring(
					0, (long) body.get_size()).split("\n")) {
					var line = raw.strip();
					if (line == "") {
						continue;
					}
					if (header) {
						header = false;
						continue;
					}
					var fields = line.split(",");
					if (fields.length < 3) {
						continue;
					}
					var release = fields.length > 4 ? fields[4].strip() : "";
					var eol = fields.length > 5 ? fields[5].strip() : "";
					versions += fields[0].strip().split(" ")[0];
					series_list += fields[2].strip().down();
					eols += eol;
					if (release != "" && release.ascii_casecmp(today) <= 0) {
						latest = versions.length - 1;
					}
				}
				var platform_rows = new Gee.ArrayList<Argus.Shared.OSQuery.OsVersion>();
				var int_binds = new Gee.HashMap<string, int>();
				var text_binds = new Gee.HashMap<string, string>();
				text_binds.set("platform", entry.key);
				query.selectWhere(
					"WHERE platform = $platform AND deleted_dt = 0 AND agent_id IN (SELECT id FROM agent)",
					int_binds, text_binds, platform_rows);
				var fetched = (int) new GLib.DateTime.now_utc().to_unix();
				foreach (var row in platform_rows) {
					var code = row.codename.strip().down();
					var rver = row.version.strip();
					var matched = -1;
					for (var i = 0; i < versions.length; i++) {
						if (code != "") {
							if (series_list[i] == code) {
								matched = i;
								break;
							}
							continue;
						}
						var ver = versions[i];
						if (ver != "" && (rver == ver ||
							rver.has_prefix(ver + " ") ||
							rver.has_prefix(ver + "."))) {
							matched = i;
							break;
						}
					}
					var status = -1;
					if (matched >= 0 && latest >= 0) {
						status = 1;
						if (matched < latest) {
							status = 0;
						}
						if (eols[matched] != "" &&
							eols[matched].ascii_casecmp(today) < 0) {
							status = 0;
						}
					}
					row.os_updated = fetched;
					row.os_status = status;
					query.updateById(row);
					changed = true;
				}
			}
			if (changed) {
				this.app.db.backupDB();
			}
			this.checking = false;
		}
	}
}
```

## LLM notes

- 🚫 Do not have each agent check whether the OS release is current. The server does that, once a week.
- 🚫 Do not fetch a release file for an OS platform that is not in `os_version`.
- 🚫 Do not add a separate table or file for release fetch times. `os_version.os_updated` stores when we fetched.
- 🚫 Do not invent a release list. A family with no file leaves `os_status` empty.
- 🚫 Do not mark a ✔️ line ✅.
