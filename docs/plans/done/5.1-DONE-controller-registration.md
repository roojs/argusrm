# 5.1 Controller registration

**Status:** ✔️ done. The Unix socket is controller id `0` and is not an `agent` row. Remote enroll and off-box hello are [5.3](../5.3-controller-remote-registration.md).

**Pointer:** `docs/guide-to-writing-plans.md` — **Checklist for plans**. Proposed Vala must follow `docs/coding-standards.md`.

**Parent:** [5.0](../5.0-controller.md), [1.0](../1.0-aims.md)

---

## Purpose

- 🔷 The Unix socket is a special controller. Its id is `0`.
- 🔷 `Command.run` `unknown agent` is not that socket.
  - The caller may be Unix. That is already allowed.
  - The error is: no app-socket TLS connection has `SslConnection.agent_id` equal to the `--agent` id.
  - The target machine is not connected, or that id is wrong.
- 🔷 Do not enroll the local controller with a PIN. It is already on `argus.sock`.
- ℹ️ Remote enroll (`--register`, cert, `is_controller`) is [5.3](../5.3-controller-remote-registration.md). That is not agent `0`.
- 🔷 Controllers and agents share the `agent` table. Remote controllers are later rows with `is_controller`.
- 🔷 Id `0` is reserved for the Unix socket. It is not a row.
- 🔷 You cannot `--agent 0 --command`. Id `0` does not run a shell.
- 🔷 Notifications still go to that Unix connection, and can come from it.
- ℹ️ [3.0 Phase 2](../3.0-server.md): the local controller is the Unix socket.
- ℹ️ [4.0](../4.0-data-types.md): other rows are `AUTOINCREMENT` from `1`.

---

## Agent `0`

- 🔷 `0` is the Unix socket. It is not stored in `agent`.
- 🔷 `--agent 0` is refused. The controller is not a machine you connect to.
- 💩 `SslConnection.agent_id` default moves to `-1`. `0` is the Unix controller, not "unset".

---

## Commands

- ℹ️ `--pin` / `--agents` / `--command` stay on the Unix socket for the box that runs Argus.
- 🔷 `--register` is later. It is a remote control client, not agent `0`.
- 🔷 `--register` is alone. It does not hello on `argus.sock`.
- 🔷 The identifier for that registration is the machine username.
- 🔷 The user certificate goes in that user's password keyring.
  - Not a file you can copy off the disk.
  - You cannot steal the cert and log in as the controller.
- 💩 It browses, then asks for the six digits on stdin.
  - Same browse/PIN loop as headless `argus-agent`.
  - `--host` / `--port` are not in this plan.
- 💩 `--pin`, `--agents`, and `--command` still hello first.
  - Unix `argus.sock` when that file exists.
  - Otherwise TLS to the stored `server` with the cert from the keyring.

## Phase 1 — Unix socket is agent `0`

- 🚫 Do not insert id `0` into `agent`. The Unix socket is the connection, not a machine.
- ✔️ TLS `agent_id` starts at `-1` until a cert row is found.
- ✔️ Handshake stamps `agent_id` from the cert so `Command.run` can find that machine.
- ✔️ `Command.run` with `agent_id < 1` replies that the controller does not run commands.
- 🚫 `--register` is not this phase.

#### Add — new file `controller/Register.vala`

```vala
namespace Argus.Controller
{
	/**
	 * Enroll this process as a control client.
	 *
	 * Browses for the PIN window, asks for six digits, and calls
	 * {@link Argus.Shared.Register} with {@link Argus.Shared.Register.is_controller}
	 * set. {@link Application} does not hello.
	 *
	 * == Example ==
	 *
	 * {{{
	 * new Argus.Controller.Register(app).run();
	 * }}}
	 */
	public class Register : GLib.Object
	{
		public Application app;

		public Register(Application app)
		{
			this.app = app;
		}

		/**
		 * Browse, take the PIN, and register.
		 */
		public void run()
		{
			var browse = new Argus.Shared.Browse();
			browse.start();
			this.app.cli.print("Looking for a management server…\n");
			var found = browse.poll();
			while (found == "") {
				GLib.MainContext.default().iteration(true);
				found = browse.poll();
			}
			browse.stop();
			if (found == "none") {
				this.app.cli.printerr("No management server found.\n");
				return;
			}
			var newline = found.index_of("\n");
			if (newline <= 0 || !GLib.Uuid.string_is_valid(found.substring(0, newline))) {
				this.app.cli.printerr("No management server found.\n");
				return;
			}
			var hostport = found.substring(newline + 1);
			var colon = hostport.last_index_of(":");
			if (colon <= 0) {
				this.app.cli.printerr("No management server found.\n");
				return;
			}
			var port = 0;
			if (!int.try_parse(hostport.substring(colon + 1), out port) || port <= 0 || port > 65535) {
				this.app.cli.printerr("No management server found.\n");
				return;
			}
			var registration = new Argus.Shared.Register() {
				is_controller = true
			};
			while (true) {
				this.app.cli.print("Enter registration PIN: ");
				GLib.stdout.flush();
				var line = GLib.stdin.read_line();
				if (line == null) {
					this.app.cli.printerr("\n");
					return;
				}
				var pin = line.strip();
				var valid_pin = pin.length == 6;
				for (var i = 0; valid_pin && i < pin.length; i++) {
					if (pin[i] < '0' || pin[i] > '9') {
						valid_pin = false;
					}
				}
				if (!valid_pin) {
					this.app.cli.printerr("Enter the six digits.\n");
					continue;
				}
				var code = registration.try_connection(
					hostport.substring(0, colon),
					(uint16) port,
					pin,
					GLib.Environment.get_host_name()
				);
				if (code != 0) {
					this.app.cli.printerr("Registration failed: %d\n", code);
					continue;
				}
				this.app.cli.print("Registration succeeded.\n");
				this.app.code = 0;
				return;
			}
		}
	}
}
```

- 🚫 Do not write certs under `AGENT_DATA_DIR`.
- 🚫 No `RegisterWindow` in this plan. CLI only, same as 5.0.
- 🚫 Do not infer `is_controller` from `family`.
