## Purpose

- 🔷 Fill the columns osquery does not have.
- 🔷 Machines keep the column list. [5.8](5.8-assets-page.md). Software keeps its column list. [5.9](5.9-assets-software.md).
- 🔷 A later refresh sends the difference, not the whole snapshot again.
- ℹ️ Column names are [4.0](4.0-data-types.md).

---

## Columns

Helpers fill these when the agent fetches. The server stores them.

- 🔷 `os_version` stores `os_updated`. When that host last refreshed its OS update information.
- 🔷 `os_version` stores `updates_outstanding`. Whether packages are waiting to be installed.
- 🔷 `deb_packages` stores `update_available` on each installed package.
- 🔷 `rpm_packages` stores `update_available` on each installed package.
- 🔷 Needs updating on a host is the OS status circle in [5.8](5.8-assets-page.md).
- 🔷 Needs updating on a package row is `update_available`.
- ℹ️ The helper reads the update state already on the host. It does not run the update.
- ℹ️ `deb_packages` from osquery is `/var/lib/dpkg`. `apt_sources` is the repository lines in `/etc/apt`.
- ℹ️ [8.0](8.0-nagios.md) still names `check_apt`. These columns are not that plugin.
- 💩 `os_updated` is the unix time, `0` when that refresh has not happened. `updates_outstanding` is `1` or `0`. Confirm the names.
- 💩 The host flag comes from the same read as `update_available`, so the two do not disagree.
- 💩 OS status is green when nothing is waiting, and red when packages are.

## Refresh

Startup may send the full tables. A later refresh does not send rows that have not changed.

- 🔷 The startup send stays a full snapshot. That query stays for now. [5.9](5.9-assets-software.md).
- 🔷 The refresh is differential.
- 🔷 It includes the update columns and the installed packages that changed.
- ℹ️ A changed install is a package added, a package removed, or a version that moved. An `update_available` that flipped is a change too.
- ℹ️ `Row.sync_rows` treats the array as the whole set for that agent. A row left out is deleted. `OSQuery.sync` is that full set.
- 💩 The refresh sends the one `os_version` row, the package rows that changed, and the keys of packages that were removed. It is not `OSQuery.sync`.
- 🔷 ⏳ When the refresh runs is not set.

## LLM notes

- 🚫 Do not call this apt updated. It is OS updated.
- 🚫 Do not have the helper run the update. The lists are already on the host.
- 🚫 Do not send a partial package list through `OSQuery.sync`. A row left out is deleted.
- 🚫 Do not add `update_available` to `programs`.
- 🚫 Do not build this before the data and the pages.
- 🚫 Do not take the startup software query out while that later pass is still open.
- 🚫 Do not mark a ✔️ line ✅.
