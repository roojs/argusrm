## Purpose

- 🔷 `⏳` Install a SysV init script that runs `argus-agent --service`.
- 🔷 `⏳` Install the Polkit policy in Debian and RPM agent packages.
- 🔷 `⏳` Do not enable or start the agent on first package installation.
- 🔷 `⏳` Let registration perform initial service enablement and startup.
- 🔷 `⏳` Restart an already-enabled agent during Debian upgrades.
- 🔷 `⏳` Support the same upgrade rule with systemd or SysV init.

## SysV service

### 1. `packaging/sysvinit/argusrm-agent.in` — add the agent init script

**Why:** `ServiceManager` already falls back to the configured init script when systemd is not running.

**Where:** add the new file.

**Depends on:** none.

#### Add — provide `start`, `stop`, `restart`, and `status` using `argus-agent --service`

```sh
#!/bin/sh
### BEGIN INIT INFO
# Provides:          argusrm-agent
# Required-Start:    $network $remote_fs
# Required-Stop:     $network $remote_fs
# Default-Start:     2 3 4 5
# Default-Stop:      0 1 6
# Short-Description: Argus remote management agent
### END INIT INFO

PATH=/sbin:/usr/sbin:/bin:/usr/bin
DESC="Argus remote management agent"
NAME=argusrm-agent
DAEMON=@AGENT_EXECUTABLE@
PIDFILE=/run/$NAME.pid
export XDG_DATA_HOME=@AGENT_STATE_DIR@
export ARGUS_LOG_DIR=@LOG_DIR@

. /lib/lsb/init-functions

case "$1" in
	start)
		log_daemon_msg "Starting $DESC" "$NAME"
		mkdir -p "$XDG_DATA_HOME" "$ARGUS_LOG_DIR"
		start-stop-daemon --start --quiet --background --make-pidfile --pidfile "$PIDFILE" --exec "$DAEMON" -- --service
		log_end_msg $?
		;;
	stop)
		log_daemon_msg "Stopping $DESC" "$NAME"
		start-stop-daemon --stop --quiet --retry=TERM/30/KILL/5 --pidfile "$PIDFILE" --exec "$DAEMON"
		RESULT=$?
		if [ "$RESULT" -eq 0 ]; then
			rm -f "$PIDFILE"
		fi
		log_end_msg "$RESULT"
		;;
	restart|force-reload)
		"$0" stop
		"$0" start
		;;
	status)
		status_of_proc -p "$PIDFILE" "$DAEMON" "$NAME"
		;;
	*)
		echo "Usage: $0 {start|stop|restart|force-reload|status}"
		exit 1
		;;
esac

exit 0
```

### 2. `meson.build` — configure and install the SysV script

**Why:** The script must use the same configured executable, state, log, and init paths as the compiled agent.

**Where:** add the executable path before `paths_vala`; configure the script after `paths_vala`; install it in the Linux install block.

**Depends on:** §1.

##### Part 1 — configured executable path

#### Add — derive the absolute agent executable path after `localstatedir`

```meson
bindir = get_option('bindir')
if not bindir.startswith('/')
	bindir = get_option('prefix') / bindir
endif
agent_executable = bindir / 'argus-agent'
```

##### Part 2 — configured init script

#### Add — generate the script immediately after `paths_vala`

```meson
agent_sysvinit = configure_file(
	input: 'packaging/sysvinit/argusrm-agent.in',
	output: 'argusrm-agent',
	configuration: {
		'AGENT_EXECUTABLE': agent_executable,
		'AGENT_STATE_DIR': localstatedir / 'lib' / 'argusrm-agent',
		'LOG_DIR': localstatedir / 'log' / 'argusrm',
	},
)
```

##### Part 3 — installation

#### Add — install the executable script after the systemd units

```meson
	install_data(
		agent_sysvinit,
		install_dir: get_option('sysconfdir') / 'init.d',
		install_mode: 'rwxr-xr-x',
	)
```

### 5. `debian/rules` — suppress first-install agent startup

**Why:** The package installs service definitions, while registration owns initial enablement and startup.

**Where:** add after `override_dh_auto_test`.

**Depends on:** §4.

#### Add — retain normal server behavior but leave the agent disabled and stopped

```make

override_dh_installsystemd:
	dh_installsystemd -pargusrm-server
	dh_installsystemd -pargusrm-agent --no-enable --no-start

override_dh_installinit:
	dh_installinit -pargusrm-agent --no-enable --no-start
```

### 6. `debian/argusrm-agent.postinst` — restart enabled services on upgrade

**Why:** An upgrade must load the new agent only when registration previously enabled the service.

**Where:** add the new maintainer script.

**Depends on:** §5.

#### Add — distinguish initial configuration from systemd and SysV upgrades

```sh
#!/bin/sh
set -e

#DEBHELPER#

if [ "$1" = "configure" ] && [ -n "$2" ]; then
	if [ -d /run/systemd/system ]; then
		if systemctl is-enabled --quiet argusrm-agent.service; then
			deb-systemd-invoke restart argusrm-agent.service
		fi
	else
		for link in /etc/rc?.d/S??argusrm-agent; do
			if [ -e "$link" ]; then
				invoke-rc.d argusrm-agent restart
				break
			fi
		done
	fi
fi

exit 0
```
