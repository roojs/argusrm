## Available

Every column on the three package tables. `update_available` is not stored yet. [5.10](5.10-data-enrichment.md) fills it.

`deb_packages`. One installed Debian package. Stored, except the last line.

- ℹ️ `name` — package name.
- ℹ️ `version` — package version.
- ℹ️ `revision` — Debian revision.
- ℹ️ `arch` — amd64, all.
- ℹ️ `size` — installed size in bytes.
- ℹ️ `status` — dpkg state. Usually `install ok installed`.
- ℹ️ `section` — archive section. The category. `httpd`, `libs`, `admin`.
- ℹ️ `priority` — required, important, standard, optional, extra.
- ℹ️ `source` — source package name.
- ℹ️ `maintainer` — the maintainer string.
- 🔷 `update_available` — a newer candidate is on disk. Not stored yet.

`rpm_packages`. One installed RPM. Stored, except the last line.

- ℹ️ `name` — package name.
- ℹ️ `version` — upstream version.
- ℹ️ `release` — the release, as in `1.el9`.
- ℹ️ `epoch` — epoch. Usually `0`.
- ℹ️ `arch` — x86_64, noarch.
- ℹ️ `size` — installed size in bytes.
- ℹ️ `install_time` — when it was installed.
- ℹ️ `vendor` — the vendor string.
- ℹ️ `package_group` — the category. `System Environment/Daemons`.
- ℹ️ `source` — source RPM name.
- ℹ️ `sha1` — the package hash.
- 🔷 `update_available` — a newer candidate is on disk. Not stored yet.

`programs`. One installed Windows program. Stored.

- ℹ️ `name` — program name.
- ℹ️ `version` — program version.
- ℹ️ `publisher` — the publisher.
- ℹ️ `install_date` — when it was installed.
- ℹ️ `install_location` — where the files are.
- ℹ️ `install_source` — where it was installed from.
- ℹ️ `language` — language.
- ℹ️ `uninstall_string` — the uninstall command.
- ℹ️ `identifying_number` — the product code.
- ℹ️ This table has no category column and no update column.

## Shown

One row per program, added up from the machines. The stored table stays one row per machine. [5.5](5.5-controller-user-interface.md) already draws a machines count.

- 🔷 The grid does not list every stored row.
- 🔷 One row per program name, inside the table picked on the second row.
- 🔷 Debian packages, RPM packages, or Windows. One table at a time.
- 🔷 Machines. How many hosts have it installed.
- 🔷 Up to date. All of those machines, some of them, or none.
- ℹ️ That split is counted from `update_available` on the stored rows. [5.10](5.10-data-enrichment.md) fills the flag. Windows has no flag, so that cell stays empty.
- ℹ️ The count is not a column in the package tables.
- 🔷 ⏳ Sign-off is Permitted or Restricted. A program with neither is the list to flag.
- 🔷 ⏳ Group is free text, added to the ticked programs.
- 🔷 ⏳ Remove creates a task. That task is [7.0](7.0-tasks.md).
- 💩 Versions on the aggregate are the set of versions in use. One version when they match. More than one when they do not.
- 💩 The Debian list is every installed package, libraries included. The rows are still aggregated by name.
